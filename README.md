# Lakehouse-Ecommerce-Data-Pipeline
> Overview

This project implements a modern Lakehouse Data Architecture using Databricks, Apache Spark, and Delta Lake to process and analyze an e-commerce dataset.

The pipeline follows the Medallion Architecture (Bronze → Silver → Gold), transforming raw CSV files into structured analytical datasets ready for business intelligence and reporting.

The goal of this project is to simulate a real-world Data Engineering pipeline, covering ingestion, data cleaning, transformations, and analytics-ready tables.
